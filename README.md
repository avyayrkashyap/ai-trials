# ai-trials

Small UI experiments. Each one lives in its own folder and runs on its own.

## Experiments

| Experiment | What it is |
| --- | --- |
| [semantic-zoom-widgets](semantic-zoom-widgets) | Tabbed widget cards on a 50px dot grid. Drag the iPad-style corner grip to resize a card in whole cells; the card shows more detail as it gets wider (icon → key number → summary → full detail). |

## Running one

Open the experiment's `index.html` in a browser. No build step or dependencies.
